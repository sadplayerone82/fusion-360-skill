## Fasteners, plastics, bearings from manufacturers
Values read from the manufacturers' original documents (PDFs, data sheets, product databases) and spot-checked: ISO 4762 M3 d_k 5.50 /
k 3 / s 2.5 and ISO 4032 M5 s 8 / m 4.70 (ISO preview), washer ISO 7089 M3 3.2 / 7 / 0.5, SKF 608 8×22×7 C 3.45 kN C0 1.37 kN
75 000 / 48 000 rpm (SKF database), CNC Kitchen insert M3×5.7 hole 4.0 depth 6.7 (official data sheet): **all matching**.

**Fasteners** [ISO previews, Westfield, Fabory]: ISO 4762, 7380-1, 4032 from the **text of the official ISO previews** (iTeh); ISO 10642
and 7089 from two agreeing distributors (ISO previews not downloadable). Example M3:
| Standard | M3 values (mm) |
|---|---|
| ISO 4762 socket head | d_k 5.50, k 3.00, s 2.5 |
| ISO 10642 countersunk | theoretical d_k 6.72 (Westfield), angle 90°, s 2 |
| ISO 7380-1 button head | d_k 5.70, k 1.65, s 2 |
| ISO 4032 nut | s 5.50, m 2.40 |
| ISO 7089 washer | d1 3.20, d2 7.00, h 0.5 |
⚠️ Errors found in the sources: Fabory 7380-1 **M2** reports the M3 values (pitch 0.5 impossible) → not to be used; Westfield 4762 M1.6
k min typo. ISO 7380-1 does not cover M2–M2.5. ISO 4032 for D < M5 only in the 1999 edition (withdrawn).

**Heat-set inserts** [CNC Kitchen, ruthex, PEM, SPIROL, Böllhoff, Tappex]: **straight** hole for
3D printing inserts (CNC Kitchen, ruthex), **8° tapered** for injection-molding ones (PEM IUB, SPIROL, Böllhoff).
| | Outer Ø | hole (CNC Kitchen / ruthex) | hole depth | length |
|---|---|---|---|---|
| M2 | 3.6 | 3.2 / 3.2 | 4.0 / 5.0 | 3.0 / 4.0 |
| M2.5 | 4.6 | 4.0 / 4.0 | 5.0 / 6.7 | 4.0 / 5.7 |
| M3 | 4.6 | **4.0 / 4.0** | **6.7 / 6.7** | 5.7 |
| M4 | 6.3 | 5.7 / 5.6 | 9.1 | 8.1 |
| M5 | 7.1 | 6.5 / 6.4 | 10.5 | 9.5 |
Depth: length + 1 (CNC Kitchen, ruthex, Böllhoff), + 0.76 (PEM), + 2 pitches (SPIROL). Boss: 1.5–1.7 × insert Ø (3D printing)
against 2× (PEM) and 2–3× (SPIROL).
⚖️ A widespread rule of thumb («hole ≈ outer Ø − 0.4, depth ≈ length + 2») for M3 Ø4.6 would give hole **4.2** and depth
**7.7**; the manufacturers say **4.0** and **6.7**: the manufacturers prevail.

**Self-tapping screws for plastics** [Semblex PT (EJOT), Würth WÜPLAST, Bulten DELTA PT]: hole = **factor × d** by plastic type
(26–30 plastics; e.g. DELTA PT 0.8·d, range 0.72–0.88·d), boss Ø and engagement depth per plastic; counterbore d + 0.2, deep
0.3–0.5·d; Würth: slightly tapered hole 0.5–1°. Filled plastics ≥ 15 % → hole + 0.08 mm, ≥ 35 % → + 0.15 (interpolate).
⚠️ **All the data are for injection-molded plastic**: no manufacturer covers PLA/PETG or FDM parts → for 3D printing they are a
**starting point** to be verified with a test piece when the requirement depends on that value.
